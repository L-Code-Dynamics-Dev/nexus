# Anastázie — podklad administrace

Po upřesnění uživatele se rozsah určuje přímo z kódu. Hlavním výsledkem je nyní [ADMIN_CODE_REQUIREMENTS.md](ADMIN_CODE_REQUIREMENTS.md) a [jeho úplná matice](ADMIN_CODE_REQUIREMENTS.csv), podložená statickým inventářem souborů, polí, API a operací.

Dřívější [ADMIN_OPERATIONS_MATRIX.csv](ADMIN_OPERATIONS_MATRIX.csv) je seznam provozních hypotéz z historického auditu. Není potvrzeným seznamem existujících funkcí a není vstupní podmínkou pokračování. Pro implementaci používat kódově odvozenou matici a rozlišení API, desktop, store, domain, data, code, model, ports, demo a lokální app.
